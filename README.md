# Shahrzad Goudarzi · Research Portfolio

Source files for my research portfolio: **https://shahrzadgoudarzi.github.io**

The site presents selected research projects on economic inequality, public attitudes,
and gender beliefs. Each project page includes a short summary, analysis code
(R, Stata, Mplus), and figures.

## Projects

- **Poverty Attributions and Economic Policies:** cross-national survey, multilevel models (R, Stata)
- **Gender Stereotypes and Sexist Attitudes around the World:** two multi-national surveys, spline mixed-effects models (Stata, R)
- **Economic Policies and Attitudes toward Income Inequality:** dynamic structural equation modeling across 160+ countries (Mplus)
